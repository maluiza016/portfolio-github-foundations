# Atividade GitHub Foundations

## Sobre esta atividade

Esta atividade faz parte do trabalho avaliativo da disciplina de Design Profissional.

Após concluir a trilha GitHub Foundations, foram aplicados neste repositório conceitos relacionados ao uso do Git e GitHub.

## Conceitos praticados

- Repositórios;
- Commits;
- Branches;
- Pull Requests;
- Merge;
- Markdown;
- README.

## Objetivo

Demonstrar, na prática, a utilização dos principais recursos apresentados durante a trilha GitHub Foundations.
