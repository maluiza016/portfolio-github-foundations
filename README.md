# Portfólio GitHub Foundations

## Autora
Maria Luiza Machado - Estudante de Engenharia de Software

## Sobre o projeto

Este repositório foi desenvolvido como atividade prática da disciplina de Design Profissional. Sua finalidade é aplicar os conhecimentos adquiridos durante a trilha GitHub Foundations, utilizando recursos do Git e GitHub para criação e gerenciamento de um projeto. 

## Objetivos

- Praticar o uso do GitHub;
- Criar e organizar um repositório;
- Realizar commits com mensagens claras;
- Trabalhar com branches;
- Criar e utilizar Pull Requests;
- Realizar merge de alterações;
- Desenvolver boas práticas de versionamento.

## Tecnologias e ferramentas

- Git
- GitHub
- Markdown

## GitHub Foundations
Este projeto foi desenvolvido após a conclusão da trilha GitHub Foundations da Microsoft Learn.
